- Cactus graphs (argument, unreviewed; note §3): for independent cycle weights in the cycle window, any d, P_w is real-rooted and real stable

  self-energy σ(τ) is affine in τ with Im σ < 0 on [−2, 2], so the zero-free set contains a half-plane around [−2, 2], and
  Grace–Walsh–Szegő gives the polarisation no zero there. The identity of step 1 was checked exactly on four cacti, d = 1..4.
