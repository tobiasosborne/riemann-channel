## 2. Setting, definitions, main results [paper]

**Task.** Prepare the state proportional to A^{-1}|b>. Hypotheses (2609.12284:pdp.tex:96):
`\norm A\le 1,\qquad \sigma_{\min}(A)\ge\kappa^{-1},\qquad \kappa\ge 1.`
and "We do not assume that $A$ is Hermitian or normal." (2609.12284:pdp.tex:123).

**Mixing time.** Worst case over all initial states, trace distance to a pure target
(pdp.tex:139-140):
`\tmix(\eps)=\inf\left\{t\ge0:` / `\sup_{\rho_0}D(\ee^{t\mathcal M}(\rho_0),P_*)\le\eps\right\}.`

**Construction.** System H_S = H_x (+) span{|r>}, dimension N+1. Residual map
F(|v>> + a|r>) = A|v>> - a|b>, i.e. F = (A, -|b>). Its kernel is one-dimensional,
spanned by |psi> = (|x>> + |r>)/sqrt(s^2+1), s = ||A^{-1}b||, 1 <= s <= kappa.
P = |psi><psi|, Q = 1-P, R = |r><r|, G = F^dagger F, reset overlap p = Tr(PR) = 1/(s^2+1).
Key gap (2609.12284:pdp.tex:217): `\kappa^{-2}Q\le G\le 2Q.`

Jumps (2609.12284:pdp.tex:225): `J_j=\ket r\bra jF,\qquad j=1,\ldots,N.`
"The generator has no Hamiltonian term:" (2609.12284:pdp.tex:237), and summing the jumps
gives (2609.12284:pdp.tex:242) `&=\Tr(G\rho)R-\frac12\{G,\rho\}.`
So L(rho) = Tr(G rho) R - (1/2){G, rho}: a no-event evolution exp(-tG/2) that is
Hermitian-dissipative, a total exit flux Tr(G rho), and a reset into the fixed state |r>.
Stationarity (2609.12284:pdp.tex:261): `GP=PG=0,\qquad \Lin(P)=0.`
Population monotonicity: "Thus target population is nondecreasing in the unconditional
density matrix. This is an ensemble statement; ..." (2609.12284:pdp.tex:303).

**Theorem 1 (thm:mix), "Uniform mixing for the pure-reset generator"**
(2609.12284:pdp.tex:395). Under the hypotheses, "the unique stationary density matrix of
\eqref{eq:lindblad} is $P$" (2609.12284:pdp.tex:396) and for all rho_0, t >= 0
(2609.12284:pdp.tex:399-400)
`\le\sqrt{\Tr(Q\rho_0)}\,` `2^{-\frac12\lfloor t/(3\kappa^2)\rfloor}.`
hence t_mix(eps) <= (2609.12284:pdp.tex:406) `3\kappa^2\left\lceil2\log_2\frac1\eps\right\rceil`.
Dimension-independent, prefactor <= 1.

**Proposition (prop:lower), "Sharp conditioning and precision dependence"**
(2609.12284:pdp.tex:999): for every kappa there is an input with
(2609.12284:pdp.tex:1002) `\tmix(\eps)\ge\kappa^2\log\frac1\eps,`
using A = diag(1, 1/kappa), b = |1>, rho_0 = |2><2|, where <2|rho_t|2> = exp(-t/kappa^2)
exactly. Scope, in the author's words: "The lower bound is not an oracle lower bound for
linear-system solving, nor a lower bound for every purely dissipative design. Its input
has an easily prepared solution, and initialization at $\ket r$ does not populate the slow
mode used in the proof." (2609.12284:pdp.tex:1051)

**Implementation.** Prop. (prop:Fencoding): explicit O(1)-query block encoding of F/2;
Prop. (prop:swapencoding): collective jump encoding via a register SWAP; Corollary
(cor:queries): expected query complexity O(kappa^2 log(1/eps) log(kappa/eps)/loglog(kappa/eps))
by invoking the CKBG simulation theorem, which "simulates a unit-normalized purely
dissipative generator" (2609.12284:pdp.tex:895) — used as a black box. Outlook: "Optimal
coherent algorithms have better conditioning dependence ($O(\kappa\log(1/\eps))$)"
(2609.12284:pdp.tex:1056).

## 3. Proof idea of Theorem 1 [paper], with a reading [inferred]

[paper] Introduce f = Tr(P rho_t), q = 1 - f, j = Tr(G rho_t), u = Tr(G^+ rho_t) with G^+
the Moore-Penrose inverse (0 <= G^+ <= kappa^2 Q). The inverse-weighted reset overlap
(2609.12284:pdp.tex:481) `\beta:=\frac{\bra rG^+\ket r}{p}` is computed by a rank-one
(Sherman-Morrison type) identity for (FF^dagger)^{-1}|b> with FF^dagger = AA^dagger + |b><b|,
and bounded by beta <= kappa^2. Then (2609.12284:pdp.tex:515) `u'(t)=\beta f'(t)-q(t),\qquad`
Integrating over [t, t+T] and using u >= 0, u <= kappa^2 q and monotonicity of q gives
(T - kappa^2) q(t) <= (T + kappa^2) Delta f, i.e. (2609.12284:pdp.tex:549)
`q(t+3\kappa^2)\le\frac12q(t).` Iterate, then D <= sqrt(q) for a pure target.
No spectral information is used at any point.

[inferred, one line] In the Heisenberg picture L^dagger(X) = Tr(RX) G - (1/2){G,X}, so
L^dagger(G^+) = p beta G - Q and L^dagger(P) = p G, hence

    L^dagger(G^+ - beta P) = -Q.

The proof is therefore a **Poisson-equation / mean-absorption-time argument**: the
observable Y = G^+ - beta P solves L^dagger Y = -(1-P), is bounded (-beta P <= Y <= kappa^2 Q),
so the integrated residual population is at most 2 kappa^2 q(0); monotonicity of q then
gives a Markov-inequality halving step. This is the quantum analogue of "t_mix <~ max
expected hitting time x log(1/eps)" for an absorbing chain.

## 4. Facts about the paper's generator that the paper does not state [inferred, numerically checked]

Checked with numpy on random complex A (N = 3, 4, 5, 8), agreement to 1e-14; scripts were
in the session scratchpad (`reset_check.py`, `reset_check2.py`), not committed.

**(i) Exact spectrum.** With lambda_0 = 0 < lambda_1 <= ... <= lambda_N the eigenvalues of G
(= squared singular values of F),

    spec L = {0}  U  { -sigma_j(A)^2 : j = 1..N }  U  { -(lambda_i + lambda_k)/2 : i != k, 0 <= i,k <= N }.

Reason: in the G-eigenbasis, off-diagonal matrix units and P span an L-invariant subspace
on which L = -(1/2){G,.}; the quotient (populations a_j) is the paper's eq. (modeflow),
M = -Lambda + |r_j|^2 lambda^T, whose characteristic polynomial is
prod_j (z+lambda_j) (1 - <b|(z+FF^dagger)^{-1}|b>) = det(z + FF^dagger - |b><b|) = det(z + AA^dagger)
(matrix determinant lemma; uses F|r> = -|b>). So all eigenvalues are real.

**(ii) Spectral gap is Theta(kappa^-2) and matches the mixing rate.** Since FF^dagger >= AA^dagger,
lambda_1 >= sigma_min(A)^2, so gap = min(sigma_min(A)^2, lambda_1/2) lies in
[sigma_min(A)^2/2, sigma_min(A)^2]. In the lower-bound instance the rates are
{0, 1/(2k^2) (x2), 1/k^2, 1, ...}: the slowest mode is the psi-|2> coherence at half the
population rate. So here gap^{-1} and t_mix agree up to constants and log(1/eps): no cutoff,
no dimension-dependent burn-in, no transient amplification (prefactor sqrt(q_0) <= 1).

**(iii) Jordan blocks occur at codimension one and the theorem is blind to them.** When a
population rate sigma_j(A)^2 equals a coherence rate (lambda_i+lambda_k)/2 whose matrix unit
has non-zero overlap with R, L is not diagonalizable. Checked: A = diag(1, 1/3),
b = (cos th, sin th), th* = 0.49088...: the eigenvalue -1/9 has algebraic multiplicity 3,
geometric multiplicity 2 (one 2x2 Jordan block). Theorem 1 holds uniformly in (A, b), so the
trace-distance mixing bound does not see this Jordan block (t e^{-t/9} is absorbed in
constants). Same moral as "Weil positivity is blind to Jordan blocks".

**(iv) cMPS reading.** With R_j = J_j and Q_cMPS = -G/2, the transfer generator is
T = -(1/2)(G (x) 1 + 1 (x) G-bar) + sum_j J_j (x) J_j-bar, and
sum_j J_j (x) J_j-bar = (|r> (x) |r-bar>) (sum_j <j|F (x) <j|F-bar) has rank one, so T is a
rank-one perturbation of a "free" generator. Hence (matrix determinant lemma)
det(z - T) = det(z - K) * (1 - <<G|(z-K)^{-1}|R>>), so the ring zeta 1/det(z-T) factorises
into a free part and a secular factor whose zeros are -spec(AA^dagger). There is no grading
and no fermionic structure in the paper.

## 5. Relevance to the programme

**(a) Ramanujan / uniform rate / spectral gap vs mixing time — suggestive, one useful tool.**
The paper gives no general relation between spectrum and mixing time; its theorem is
spectrum-free. For its own generator, gap and mixing rate agree (fact ii), so it is a
"benign" example, not a non-normal one. The transferable item is the method: a bounded
solution of the Poisson/Lyapunov equation certifies uniform worst-case exponential mixing.
For the notebook's absorbing-vacuum channel (def:vacuum-decay) the analogous quantities are
q(t) = Tr(Z_t X Z_t^dagger) and the Gramian W = int_0^inf Z_t^dagger Z_t dt (finite N:
B^dagger W + W B = -1); sup_rho D(rho_t, Omega) lies between ||Z_t||^2 and ||Z_t||.
This leads to a genuinely relevant observation:

[inferred, elementary, unconditional; conventions of report/sections/02b_definitions_arithmetic.tex:23-29]
For inner S on the lower half-plane and phi_t(z) = e^{-itz}, the model-space kernel estimate
gives ||Z_t|| >= |phi_t(w)| - |S(w)| = e^{-t eps} - |S(x - i eps)| for w = x - i eps.
For S(tau) = xi(1-2i tau)/xi(1+2i tau), Stirling gives a Gamma ratio ~ x^{-2 eps} and the
convexity bound gives |zeta(1-2eps+2ix)| << x^{eps+delta}, while |zeta(1+2eps+2ix)| is bounded
below; so |S(x - i eps)| -> 0 as x -> inf for each fixed 0 < eps < 1/4
(mpmath: eps = 0.2 gives |S| = 0.72, 0.60, 0.095, 0.027 at x = 10, 100, 1000, 5000).
Hence **||Z_t|| = 1 for every t >= 0, independently of RH**: the Riemann semigroup is not
uniformly exponentially stable, the Riesz-basis/Lyapunov certificate "A^dagger G + G A = -2 Delta G,
G bounded invertible" cannot hold on all of K_S, and the absorbing-vacuum channel on
C (+) K_S has **infinite worst-case trace-distance mixing time**. Consequently RH cannot be
a worst-case mixing statement for these channels; any mixing-time form of "all rates 1/4"
must restrict initial states or use a weighted norm (compare the paper's own remark that
initialization at |r> avoids the slow mode, pdp.tex:1051). This needs a check of the
kernel inequality's conventions by a second reader before it enters the report.

**(b) cMPS, transfer generators, ring quantities, grading — not relevant beyond fact (iv).**
Nothing on MPS/cMPS, boundary or ring quantities, fermions or supertraces. Fact (iv) is a
generic property of rank-one reset bonds, not something the paper uses.

**(c) KMS / detailed balance / Gibbs / symmetry / phase transitions — not relevant.**
The fixed point is pure, so no faithful-state detailed balance, no log-Sobolev or chi^2
machinery; KMS Gibbs samplers appear only as citations in the introduction (pdp.tex:66).
No symmetry, no phase transition, no ergodicity breaking. Structurally the generator is in
the notebook's "fixed no-event generator plus scalar reset" class
(report/sections/04d_bc_symmetry_generators.tex:233-236) and is a cousin of the vacuum-decay
model, with the difference that the dark state psi is annihilated by the no-event
generator while the reset target |r> overlaps it (p > 0), which is what makes the
population block a nontrivial rank-one feedback.

**(d) Quantum expanders, Hastings bound, Ramanujan graphs, cutoff — not relevant.**
None appear. The paper's bound has no cutoff (prefactor <= 1 from t = 0). Rates range over
[kappa^-2/2, 2], so no "one rate" structure.

## 6. Follow-ups, ranked

1. **Truncated Riemann semigroup non-normality.** For the Blaschke product with the first N
   zero pairs (w = -gamma_n/2 - i/4), compute in the normalized-kernel basis (where Z_t^* is
   diagonal) the Gram condition number cond(Gamma_N), M_N = sup_t e^{t/4} ||Z_t^{(N)}||, and
   ||W_N|| (compare with 2, the value for a normal operator with all population rates 1/2).
   Test: M_N and ||W_N|| grow without bound in N (predicted by the ||Z_t|| = 1 argument);
   measure the growth law against the zero density log(gamma/2pi). Cheap, decisive for
   TJO's "non-normal/Jordan effects" hypothesis.
2. **Second-reader check of ||Z_t|| = 1** (kernel inequality, convention of which exponential is
   inner, the Gamma/zeta bound). If confirmed, record as a proved negative: "no worst-case
   mixing-time form of RH for the Riemann/absorbing-vacuum channel".
3. **Restricted mixing.** Find the natural initial-state class (e.g. X with Tr(X W) finite, or
   smooth vectors / domain of a power of B) on which the paper's Poisson-equation argument
   does go through, and check whether "all modes at rate 1/4" is then equivalent to a uniform
   exponential bound on that class (a Gearhart-Pruss-type statement in a weighted norm).
4. **Record facts (i)-(iii)** for reset Lindbladians L = Tr(G.)R - (1/2){G,.} as a small
   worked example of "gap = mixing rate, Jordan blocks invisible to trace-distance mixing".
5. Low priority: ring zeta of rank-one reset bonds via the determinant lemma (fact iv), as a
   toy for sdet factorisations; unlikely to reach arithmetic content.

## 7. Caveats: what the paper does not give

- No relation between spectral gap and mixing time for general (non-normal) Lindbladians;
  its bound is for one explicit family and is proved without spectrum.
- Finite dimension throughout; the "dimension independence" is uniformity in N for fixed
  kappa, not an infinite-dimensional theorem, and says nothing about unbounded generators.
- No cMPS, no grading/fermions, no KMS/detailed balance, no symmetry, no expanders, no cutoff,
  no Ramanujan or number theory.
- The lower bound is for this family only (author's own caveat, pdp.tex:1051).
- The query-complexity corollary rests on an external simulation theorem not reproved.
- Everything in sections 4 and 5(a) marked [inferred] is mine; the ||Z_t|| = 1 claim in
  particular is unreviewed.
