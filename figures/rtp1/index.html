RTP-1 figures

Figures for round 1 of the Riemann Tomography Problem (notes/rtp-round-1/brief.md, notes/rtp-round-1/viz-brief.md), one set per step. Figures are secondary sources: each caption says which panels plot certified data from a lane's committed output and which are recomputed for display. Author: claude:opus (lane V). Built by python3 viz/rtp1/make_all.py.

Game rule 2 applies to the figures: zeros of zeta appear only in panels labelled "comparison (zeros used)" (Step 1 envelope panel b; Step 2 explicit-formula panels). Every other number comes from primes, the pole and the archimedean place.

Each figure has a dark-surface variant (<id>.dark.png/.svg, shown when the system is in dark mode) and a table view data/<id>.csv with the plotted numbers.
