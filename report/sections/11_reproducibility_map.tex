\section{Reproducibility Map}
\label{sec:repro}

Every numerical claim in this book points to a script under
\texttt{scripts/} whose standard output is captured under
\texttt{outputs/}. All scripts run from the repository root with
\texttt{python3} and need only \texttt{numpy}, \texttt{scipy},
\texttt{mpmath} and \texttt{sympy}. Random data are seeded. The local CI
re-runs the fast scripts and diffs their output against the captured files.

\subsection*{Data}

\texttt{data/zeros3000.npy}: the first $3000$ imaginary parts of the zeta
zeros, from \texttt{mpmath.zetazero}. \texttt{data/ringnorm.npz}: the arrays
of the ring-norm test.

\subsection*{Reference sources}

\texttt{refs/fetch\_sources.sh} downloads the arXiv TeX source of every cited
paper into \texttt{refs/src/<id>/} (not redistributed) and writes
\texttt{refs/manifest.sha256}. Every quote in \texttt{db/provenance.tsv} is
byte-checked by the gate at its stated \texttt{<id>:<file>:<line>}.

\subsection*{Reviews}

\texttt{notes/reviews/} holds the adversarial review reports; a
\texttt{proved} claim names its review file in \texttt{db/claims.tsv} and the
gate checks that the file contains \texttt{VERDICT <id>: VALID}.
